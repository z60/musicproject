**当前状态（实测）**：


### 5.0.1 模板表达式教训（与 5.1 同级，值得记一笔）

`src/renderer/src/**/*.vue` 里曾有 **133 处** 内联箭头函数带 TypeScript 类型标注：

```html
<!-- ❌ 模板不是 TypeScript：vue-tsc 报 TS1109「Expression expected」，
     并且**放弃该文件的其余类型检查** —— 于是真正的问题一个都看不到 -->
<el-slider @update:model-value="(value: number | number[]) => setPause(Number(value))" />

<!-- ✅ 把处理逻辑搬进 <script setup lang="ts">，模板只引用函数名。
     参数类型由命名函数显式声明；子组件的事件类型由 defineEmits 推断。 -->
<el-slider @update:model-value="onPauseSliderInput" />
```

删掉标注后，`vue-tsc` 立刻暴露出 **137 个此前被掩盖的真实类型错误**（隐式 any、
可空 props、`retryFn` 返回值不兼容、`Record<CleanOptionKey, boolean>` 的键退化等）。
**这就是「跳过整个文件」的代价：不是少报几个错，而是整片区域无人看守。**
现在这条由 `check:template-types` 门禁守住。

### 5.0 测试隔离：为什么用 Worker 线程

三种方案都试过，结论写在这里免得后来者重走：

| 方案 | 结果 |
|------|------|
| **同进程** import 各测试文件 | ❌ 模块级状态互相污染，表现为「单独跑都过、一起跑有 8 项失败」 |
| **子进程**（`node --test` 的官方做法） | ❌ 本环境禁止 spawn：`spawnSync ... EPERM`；实测 `node --test` 41/41 全挂 |
| **Worker 线程** | ✅ 可用。每个 Worker 有独立模块注册表，等价文件级隔离，且在无沙箱限制的机器上同样有效 |

**顺带修掉的两个真实缺陷**（由测试抓出，都在基础设施层）：

1. **`TaskQueue.dispose()` 不等在跑任务落终态**：`cancel()` 对 running 任务只设 abort 信号就返回，`dispose` 直接 `await` 它就以为完成了 —— 调用方随后查状态会看到 `running`，而这些任务会以 `running` 留在库里（应用已退出，只能等下次启动才被标为 interrupted）。已改为等待 `RunningEntry.done`，带**可清除的超时**兜底。
   - 附带教训：第一版兜底用了裸 `setTimeout` 做 race，任务早已完成后事件循环仍等到超时才退出，**把一个 300ms 的测试拖成 30 秒**。现在超时计时器在 `finally` 里清除。
2. **`queue.test.ts` 的 `createHarness` 参数错位**：4 处调用把选项当第一个参数传（`createHarness({ retryDelaysMs: [...] })`），specs 收到对象 → `opts.specs is not iterable`。已在 harness 内归一化参数，两种调用方式都支持。

### 5.1 一个代价很大的教训：注释里的 `/*` 会毁掉解析

**现象**：`src/main/bootstrap/cleanup.ts` 无法被 import，报
`Expected '{', got 'interface'` —— 报错位置指向的 `interface` 完全合法。
最终定位到该文件第 31 行的 JSDoc：

```ts
/** 要清理的临时目录根（如 `<userData>/cache/tmp`、`<projects>/*/.tmp`、任务临时根） */
//                                          ^^^^^^^^^^^^^^^^
```

`/*` 让类型剥离解析器**重新进入嵌套块注释**，注释永不闭合，后续内容全被吞掉。
排查期间我反复怀疑 "interface 有问题"、怀疑文件被并发写入、怀疑有隐藏字符，
浪费了大量时间 —— 因为报错位置与根因无关。

**更糟的是我的修复过程**：为了消除这个隐患，我用脚本把注释里所有 `/*` 批量改写成
`* /`。该脚本**没有正确区分注释边界与 glob 写法**，把 `src/shared/*.ts` 改成了
`src/shared* /.ts`（可读性破坏），并在若干文件里**提前闭合了注释块**，
使注释文本变成代码（`app-lifecycle.ts` 因此报 `ReferenceError: recordings is not defined`），
一度让测试通过数从 1100+ 掉到 46。

**修复**：逐处按原文精确还原（不改语义、不改路径示例），并新增 `check:syntax` 的
隐患检测 —— **但判据收紧为「起始符之后本行没有结束符」**，因为
`src/shared/*.ts` 这类 glob 其实无害（注释会在本行正常闭合），
一律报警只会让检查失去可信度。

**给后来者的规矩**：写注释时不要直接写出「斜杠紧跟星号」的两字符注释起始符。
需要表达 glob 时用 `**` 或「星号与斜杠之间留空格」。

```bash
# 1. 依赖（若 node_modules 已就位可跳过）
```
