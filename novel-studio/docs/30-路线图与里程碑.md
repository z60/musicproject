## 1. 分期总览

| 期 | 主题 | 核心目标 | 交付 |
|----|------|----------|------|
| **1.0** | 全功能闭环 | 一本小说能走到可分发的 M4B 成品 | 六大功能域全部可用 |
| **2.0** | 协作与质量 | 多人分工闭环 + 质量可控 + 云端 AI 可选 | 任务包闭环、质检报告、Dify 接入 |
| **3.0** | 智能与规模化 | AI 强制对齐、TTS、跨项目音色库 | 语义级校验与补齐 |

**1.0 的范围按你的要求包含全部六大功能**（含向量判定、多轨、混音、M4B）。这是一个**大**的 1.0，所以下面把它拆成 6 个可验收的阶段（M1~M6），每个阶段都有独立可演示的产出。

## 2. 1.0 里程碑（M1~M6）

### M1 · 地基（脚手架 + 数据 + 契约）

**目标**：应用能跑起来，能把数据存进去再取出来。

| 交付 | 验收标准 |
|------|----------|
| electron-vite 脚手架（main/preload/renderer） | `npm run dev` 启动，窗口正常，安全配置符合 `02` §3 |
| SQLite 接入 + `001_init.sql` + 迁移器 | 首次启动建库成功；`integrity_check` = ok；重复启动不重复迁移 |
| repository 层骨架 + mapper | 单测：CRUD 往返一致（含 JSON 字段与 BLOB 向量） |
| `src/shared/types.ts` + `ipc-contract.ts` | 类型双向检查通过；未注册通道调用报错 |
| 通用任务队列 + `task:progress` 事件 | 一个假任务（sleep 分片）能上报进度、可取消 |
| 日志 + 崩溃恢复骨架 + 备份 | 强杀进程后重启能记录崩溃；备份文件生成成功 |
| Element Plus + 路由 + 布局壳 | 左侧导航可切换五大功能域占位页 |

**出口 DoD**：能启动、能建库、能跑一个带进度与取消的后台任务、能被强杀后正常重启。

| PDF/DOCX 解析 | 含文本层 PDF 正常；扫描版 PDF 明确报错；DOCX 标题分级正确 |

**出口 DoD**：30 MB GBK TXT 在 60 秒内完成导入与分章，可取消且不留半本书（对应 AC-1）。

| 向量判定 + 规则后处理 | 回归集准确率 ≥ 85%；输出置信度与 Top-3 候选 |
| 情绪/语速/停顿推断 | 停顿值符合 `11` §2.3 表；可配置节奏预设 |
| 表格视图 + 剧本视图 | 5000 行滚动 ≥ 30 fps；两视图共享选中位置 |

### M4 · 录音（三种模式 + 崩溃安全）

**目标**：把画本录成音频，且**永远不丢素材**。

| 交付 | 验收标准 |
|------|----------|
| AudioWorklet 采集 + MessagePort 传输 | 采集样本数 = 写盘样本数（丢帧 0） |
| WAV 增量写入 + 元数据 + 崩溃恢复 | 30 分钟后强杀进程，重启恢复的 WAV 可播放、时长正确 |
| 设备枚举 + 诊断 + 自检 | 「录 5 秒回放」自检 5 项检查全部正确 |
| 逐行录制 | 连录 20 行无需鼠标；每行 take/state 正确 |
| 连续录制 + VAD 切片 | 20 段真实朗读切片边界正确；切片匹配准确率 ≥ 95% |
| 切片确认界面 + 重切 | 改参数重切，原始会话不丢 |
| 多 take + A/B + 设为成品 | 5 个 take 全保留；成品唯一 |
| 监听返送 | 监听音量不影响录音音量；直通时有啸叫警告 |
| 快捷键 + 踏板 | 全部快捷键可用；录音中 `Ctrl+W` 被拦截 |
| 背压与磁盘保护 | 模拟写盘慢/磁盘满，停止录音且保住数据 |
| 角色模式（本地） | 只显示负责角色；画本只读 |

**出口 DoD**：连续录制 30 分钟后强制结束进程，重启能恢复完整可播放 WAV（对应 AC-3）。

### M5 · 对轨 + 处理

**目标**：把录音排到时间线上，并把音质修好。

| 交付 | 验收标准 |
|------|----------|
| 录制对齐（自动匹配 + 手动） | 87 行 87 片段自动匹配错配 ≤ 2，且被校验指出 |
| 自动排布 + 留白 | 顺序/留白/总时长符合预期；留白三级优先级正确 |
| 重叠检测与消解（4 策略） | 同轨必须消解；跨轨正常对话不误报 |
| 时间线视图（Canvas 自绘） | 1000 items 滚动/拖动 ≥ 30 fps；波形 3 级 LOD |
| 手动微调 + 吸附 + 锁定 | **拖左边缘内容位置不变的单元测试通过** |
| 校验（11 种 issue） | 每种可构造并检出；`wrong_order` 能抓到错绑 |
| 多方案 | 方案间数据不串；锁定状态正确 |
| ffmpeg 能力探测 | 缺失滤镜时 UI 隐藏对应控件且不崩 |
| 处理链 7 模块 + 预设 | 7 个内置预设的滤镜串快照一致；参数单位经测试信号验证 |
| 噪声轮廓采样 | 采样结果合理，填入后降噪效果可听 |
| 批量处理 + 失败隔离 + 取消 | 单个失败不中断整批；取消无残留 |
| A/B 试听 | 位置完全同步 |

**出口 DoD**：一章 87 行录音自动对轨后错配 ≤ 2 处；100 个片段批量处理后无残留、可取消（对应 AC-4、AC-5 前半）。

## 6. 测试策略

### 6.1 分层

| 层 | 工具 | 覆盖目标 |
|----|------|----------|
| 单元测试 | Vitest | 领域逻辑：编码嗅探、分章、切句、引号解析、判定算法、留白计算、重叠消解、滤镜串生成、时长计算、LUFS 增益计算、`dbToLinear` |
| 组件测试 | Vitest + @vue/test-utils | 画本表格、待确认队列、处理链编辑器、导出向导 |
| 集成测试 | Vitest（Node） | repository ↔ 真实临时 SQLite；队列 ↔ 任务实现；迁移器 |
| 音频验证 | 自研脚本 + ffmpeg | 生成参考信号 → 处理 → 测量（增益/滤波/压缩/限幅/响度），用数值断言而非听感 |
| E2E | Playwright + Electron | 全流程：导入→画本→录音（模拟）→对轨→处理→导出；崩溃恢复演练 |
| 回归集 | 人工标注语料 | 200 段文本的说话人标注；6 部小说的分章基准 |

### 6.2 必测的非功能项

| 项 | 方法 | 门禁 |
|----|------|------|
| 录音零丢帧 | 30 分钟录制，比对采集/写盘样本数 | 丢帧数必须 = 0 |
| 崩溃恢复 | 8 类场景自动化（含写盘瞬间杀进程） | 全部可恢复且音频可播放 |
| 响度精度 | 10 个不同素材导出，第三方工具测量 | 全部在目标 ±1 LU 内，TP ≤ 目标 |
| M4B 章节 | 脚本校验 START/END 连续无缝；3 播放器人工验证 | 通过 |
| 性能预算 | 见 `00` §4.1 全部条目 | 全部达标 |
| 无内存泄漏 | 录音/对轨/导出连续跑 2 小时，内存增长 < 10% | 通过 |
| 安全 | 渲染进程无法访问 fs；IPC 非法载荷被拒；API Key 不明文落库 | 通过 |

### 6.3 回归集建设（M3 开始，贯穿全程）

```
tests/fixtures/
├── encoding/            20 个编码样本
├── chapters/            6 部小说的分章基准（片段 + 期望章节数/标题）
├── attribution/         200 段人工标注（文本 + 上下文 + 期望说话人）
├── quotes/              引号与引导语边界用例
├── audio/               参考信号（正弦、白噪、扫频、阶跃、齿音）
└── packages/            3 个 .nst/.nsp 样本（正常/画本变更/损坏）
```

> **回归集是这类项目的真正资产**。没有它，「判定准确率 ≥ 85%」这种验收标准无法验证，也无法防止后续优化把准确率改坏。

## 7. 性能预算（验收门禁）

| 场景 | 目标 | 测量点 |
|------|------|--------|
| 冷启动到可用 | ≤ 3 s | 窗口可交互 |
| 导入 30 MB TXT + 分章 | ≤ 60 s | 任务耗时 |
| 打开一章画本（≤500 行） | ≤ 500 ms | 首屏渲染 |
| 画本行编辑保存 | ≤ 50 ms | 写库耗时 |
| 录音监听往返延迟 | ≤ 30 ms | `baseLatency + outputLatency` + 估算输入延迟 |
| 录音丢帧 | 0 | 样本数比对 |
| 时间线（1000 items） | ≥ 30 fps | 滚动与拖动 |
| 向量判定（500 行/章） | ≤ 20 s | 批量任务（CPU） |
| 渲染 15 分钟音频（含两遍响度） | ≤ 3 min | 导出任务 |
| 响度目标偏差 | ≤ 1.0 LU | 第三方测量 |
| 万行画本可操作 | 滚动 ≥ 30 fps | 10 万行库 + 5000 行章节 |
| 空闲内存 | ≤ 400 MB | 任务管理器 |
| 2 小时连续录音内存增长 | < 10% | 长稳测试 |

| R8 | embedding 模型 OOM | 中 | 中 | batch 自适应降级 + 模型量化 + 可切换模型 | 推理抛错 |
| R9 | 大章节（5000 行）编辑器性能 | 中 | 中 | 虚拟滚动 + 分页 + 纯文本降级渲染 | 帧率 < 30 |
| R10 | 模型/ffmpeg 分发许可问题 | 中 | 高（法务） | 优先 LGPL 构建；发布前逐项确认许可；`lite`/`full` 双构建 | 法务审查 |
| R11 | 连续录制切片质量差 | 中 | 中 | VAD 参数可调 + 原始会话保留 + 重切 + 手动拆分合并 | 切片不合率 > 15% |
| R12 | 任务包回收冲突（画本已变更） | 高 | 中 | `linesHash` 比对 + 差异报告 + 增量重发 | 回收报告出现差异告警 |
| R13 | 用户素材磁盘占用失控 | 高 | 低 | 清理策略可配 + 磁盘用量面板 + `.nsp` 精简选项 | 项目目录 > 50 GB |
| R14 | 范围蔓延（1.0 过大） | 高 | 高 | M1~M6 阶段化；每阶段独立可演示；范围外清单（`00` §5）明确 | 阶段延期 > 30% |

**优先级最高的三项**：R1（数据安全）、R7（UI 冻结）、R14（范围失控）。
