## 1. 这套文档是什么

这是 **novel-studio** 的完整设计文档集（不是代码）。它回答四类问题：

| 问题 | 看哪份 |

## 2. 一句话定位

> **Novel Studio 是一个本地优先的「小说 → 画本 → 录音 → 对轨 → 混音 → 有声成品」一体化工作站。**
> 它把「谁说的话」这件事从人工判断变成可复算的语义判定，把「多人分角色录音」变成可下发、可回收、可合并的工程流程。

与市面上工具的关键差异：

1. **画本是全局枢纽**：不是「文本 + 音频」两坨东西对不上，而是以 `画本行（canvas_line）` 为唯一主轴，录音片段、音色、情绪标记、时间线位置全部挂在它下面。
2. **说话人判定走向量**：引号/正则只做粗筛，真正的「这句是旁白还是某角色」由本地 ONNX embedding + 角色原型向量（centroid）余弦相似度判定，**离线可跑、可复算、可人工覆盖**。
3. **协作是一等公民**：支持「一台机器切画本 → 下发角色任务包 → 多名配音员各自录制 → 回收合并」的闭环，而不是假设全世界只有一个人在录。
4. **离线优先**：ASR（whisper.cpp）、embedding、混音（ffmpeg）全部本地；云端 LLM（Dify）是可选增强，不是硬依赖。

## 3. 技术栈基线（已锁定）

| 模块 | 技术方案 | 落在哪一侧 |
|------|----------|------------|
| UI 框架 | Vue 3 + TypeScript + Element Plus + Pinia + Vue Router | 渲染进程 |
| 桌面框架 | Electron（主进程 + preload + sandbox 渲染进程） | 主进程 |
| 录音引擎 | Web Audio API + AudioWorklet（float32 PCM 采集） | 渲染进程采集，主进程落盘 |
| ASR 识别 | whisper.cpp（本地，模型内置） | 主进程 |
| 音频处理 | fluent-ffmpeg（主进程调用，长任务子进程） | 主进程 |
| 数据库 | SQLite（`better-sqlite3` 同步 API，裸 SQL + repository 层，无 ORM） | 主进程 |
| AI 能力 | 抽象 `AIProvider` 接口；实现含 Mock / 本地 / OpenAI 兼容 / **Dify**（后续接入） | 主进程 |
| 向量判定 | 本地 ONNX 小模型（bge-small-zh 类）+ embedding 存 SQLite + JS 侧余弦相似度 | 主进程 |
| 文件打包 | JSZip / archiver（`.nsp` 项目包、`.nst` 任务包） | 主进程 |

## 5.1 出错时读哪里（错误兜底速查）

系统里任何一处抛错，最终都要变成「用户看得懂的一句话 + 一个可执行的动作 + 一个可定位的编号」。
这套机制横跨三处，按顺序读：

| 顺序 | 位置 | 回答的问题 |
|------|------|------------|
| 1 | `01-系统架构.md` §6 | **哪种故障降级到什么功能**（产品决策） |
| 2 | `01-系统架构.md` §13 | 架构接线点：三级兜底装在哪、哪些位置必须接上、验收标准 |
| 3 | `22-错误码与消息体系.md` | **完整设计**：编号规约、消息表结构、包裹规则、分级展示、测试要点 |
| 4 | `23-错误码一览.md` | **查具体编号**：`E200005` 是什么错、给用户看什么话、点什么按钮 |

配套代码（已产出，可直接落地）：

| 文件 | 作用 |
|------|------|
| `src/shared/messages.ts` | 消息表（唯一文案来源）+ 数字编号自动派生 |
| `src/shared/errors.ts` | `AppError`/`BusinessError`、工厂、包裹、序列化、兑现、日志字段 |
| `src/main/infra/errors/install.ts` | 主进程全局钩子（uncaughtException / unhandledRejection / 崩溃） |
| `src/main/ipc/registry.ts` | IPC 包裹器：校验 + 兜底 + **永不 throw**，统一返回 `{ok,data,error}` |
| `src/renderer/src/shared/lib/ipc.ts` | 渲染侧统一解包与兑现（组件禁止直接调 `window.api.invoke`） |
| `src/renderer/src/shared/lib/error-bus.ts` | 唯一出提示的口子：分级 + 去重合并 + 日志 |
| `src/renderer/src/app/error-handler.ts` | Vue / window / promise / 路由 四条路径的全局兜底 |
| `src/renderer/src/shared/ui/ErrorBoundary.vue` | 路由级错误边界，页面异常不白屏 |
| `scripts/gen-error-docs.ts` | 由 `messages.ts` 生成 `docs/23-错误码一览.md`，并做五项自检 |
| `tests/shared/errors.test.ts` | 错误体系测试，守住编号稳定、文案纪律与包裹语义 |

### 5.1.1 常用命令

> 这些脚本全部**不需要安装任何依赖** —— Node 22.6+ 原生支持 TypeScript 类型剥离
> （`--experimental-strip-types`）。在无外网环境下也能跑，这是刻意的设计。

| 命令 | 作用 |
|------|------|
| `npm test` | 跑 `tests/**/*.test.ts` 全部测试（经 `scripts/run-tests.ts`，同进程运行避免沙箱 `spawn EPERM`） |
| `npm run test:filter -- canvas` | 只跑名字含关键字（如 canvas）的测试 |
| `npm run check:structure` | **结构自检**：每个零依赖模块能否真被 import、分层方向、禁用路径别名、循环依赖 |
| `npm run check:coverage` | **覆盖度报告**：IPC 通道覆盖、错误码引用、文档可追溯性、功能域覆盖 → 生成 `docs/90-代码覆盖度报告.md` |
| `npm run errors:docs` | 由 `src/shared/messages.ts` 重新生成 `docs/23-错误码一览.md` |
| `npm run errors:docs:check` | CI 门禁：错误码文档与源码不同步则 exit 1 |
| `npm run verify` | `test` + `errors:docs:check`（提交前跑这个） |
| `npm run typecheck` | 类型检查（**需要先 `npm install`**，离线环境不可用） |
| `npm run dev` / `npm run build` | 开发 / 打包（**需要先 `npm install`**） |

> **为什么要有 `check:structure` 和 `check:coverage`**：
> 本项目的开发机无外网，`tsc` / `vue-tsc` 装不上，因此 `typecheck` 跑不了。
> 这两个脚本是在这种情况下**唯一能做的真实性检查**：
> `check:structure` 会真的去 `import` 每个零依赖模块（能抓语法错误、import 路径错误、
> 循环依赖、顶层副作用抛错），`check:coverage` 则把「文档是否真的落成代码」变成客观数字。
>
> 两个生成物是自动维护的，不要手工编辑：`docs/23-错误码一览.md`、`docs/90-代码覆盖度报告.md`。

## 6. 术语速查（读任何文档前先看这张表）

| 术语 | 英文/字段 | 含义 |
|------|-----------|------|
| 书籍 | `book` | 导入的原始文本整体，可含多章 |
| 章节 | `chapter` | 分章后的文本单元，是录音与导出的调度单位 |
| 画本 | `canvas` | 章节的「表演脚本」集合，由一个或多个画本行组成 |
| 画本行 | `canvas_line` | **唯一主轴**。一行 = 一句/一段要录的内容，带说话人、情绪、停顿、音色绑定 |
| 说话人 | `speaker` | 画本行归属：`narration`（旁白）或某个 `character` |
| 角色 | `character` | 作品内的人物，含多个别名（同一人的不同称呼） |
| 配音员 | `voice_actor` | 现实中的人，一个配音员可担任多个角色，一个角色可多候选 |
| 音色档案 | `voice_profile` | 配音员的参考录音与声学画像，供后续 TTS/匹配预留 |
| 原型向量 | `centroid` | 某角色全部台词的 embedding 均值，用于判定新句子归属 |
| 录音会话 | `recording_session` | 一次按下录音到停止之间的连续素材，落成 WAV |
| 录音片段 | `voice_segment` | 绑定到画本行的成品音频片段（可能由某个 take 裁切而来） |
| 试录 | `take` | 同一画本行的多次录制版本，可 A/B 对比后择一 |
| 对轨 | `alignment` / `arrangement` | 把片段按时间线排布成整章轨道，处理留白与重叠 |
| 任务包 | `.nst` | 下发给单个配音员的角色子集 + 空白录音位 |
| 项目包 | `.nsp` | 整个项目的可迁移归档 |
